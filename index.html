slurm-job-template-disi

template per il cluster SLURM del DISI — Università di Bologna

autore: Stefano Pio Zingaro repo: github licenza: CC BY-SA 4.0

descrizione

Template e script di esempio per sottomettere job al cluster SLURM installato presso il Dipartimento di Informatica — Scienza e Ingegneria (DISI) dell'Università di Bologna.

Raccoglie configurazioni tipiche per job CPU/GPU, gestione dell'ambiente Python, e buone pratiche per l'uso efficiente delle risorse condivise.

utilizzo rapido

git clone https://github.com/lozingaro/slurm-job-template-disi
cd slurm-job-template-disi
# modifica job.sh con i tuoi parametri
sbatch job.sh

parametri principali

  • --partition — coda di esecuzione (es. gpu, cpu)
  • --gres=gpu:1 — richiesta GPU
  • --time — limite di tempo (formato HH:MM:SS)
  • --mem — memoria RAM richiesta
